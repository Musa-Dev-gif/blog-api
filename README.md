# Blog API

I built this API myself!

## Features
- User signup with hashed password
- Create blog posts
- Get posts with author

## How to run
npm install
npx prisma migrate dev
node app.js

## Endpoints
GET / -> Blog API is running
GET /posts -> returns all posts
POST /signup -> create user
POST /posts -> create post
